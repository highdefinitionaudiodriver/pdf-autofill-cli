# PDF 自動入力 CLI v0.2.0

コマンドラインからPDFにユーザー情報を自動入力するツール。 あらかじめ定義したプロフィール(JSON)とマッピング設定に従い、PDFテンプレートの指定座標またはフォームフィールドにテキストを描画して新しいPDFとして出力します。
